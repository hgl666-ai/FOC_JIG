# 治具副芯片串口通讯协议

## 1. 物理层

| 项目 | 参数 |
|---|---|
| 接口 | USART1（治具日志口，正式上线日志关闭） |
| 波特率 | 115200 |
| 数据格式 | 8 数据位，无校验，1 停止位（8N1） |
| 方向 | 治具主芯片 <-> 治具副芯片 |

> USART1 上平时可能有 ASCII 日志。副芯片解析时应先找帧头 `A5 5C`，
> 非帧头字节直接丢弃；治具侧对副芯片的应答也做同样处理。

## 2. 帧格式

所有字段大端；CRC 为 CRC-16/MODBUS，计算范围从 `A5` 到 `DATA` 最后一个字节
（不含 CRC 本身）。

```
A5 5C | CMD(1B) | LEN(1B) | DATA(LEN) | CRC16(2B, 高字节在前)
```

- `CMD`：命令码，请求与应答使用同一个 CMD。
- `LEN`：`DATA` 字节数，0 表示无数据。
- 一帧最小 6 字节，最大 22 字节（LEN 最大 16）。

### 2.1 请求帧（治具 -> 副芯片）

| 功能 | CMD | LEN | 请求帧（含 CRC） |
|---|---|---|---|
| PING | `0x01` | 0 | `A5 5C 01 00 6A E3` |
| 读 IO 电平 | `0x10` | 0 | `A5 5C 10 00 3A EF` |
| 读 3 路电压 | `0x11` | 0 | `A5 5C 11 00 AA EE` |
| 读 3 路 ADC | `0x12` | 0 | `A5 5C 12 00 5A EE` |

### 2.2 应答帧（副芯片 -> 治具）

| 功能 | CMD | LEN | DATA 定义 |
|---|---|---|---|
| PING | `0x01` | 1 | `[0]` 协议版本，固定 `0x01` |
| 读 IO 电平 | `0x10` | 1 | `[0]` IO 位图，见下表 |
| 读 3 路电压 | `0x11` | 6 | `[0..1]` U1-3V3 mV<br>`[2..3]` U1-5V mV<br>`[4..5]` U1-24V mV |
| 读 3 路 ADC | `0x12` | 7 | `[0..1]` U1-NHT mV<br>`[2..3]` U1-NTC mV<br>`[4..5]` MER mV（固定 0）<br>`[6]` MER 数字电平（0/1） |

所有 mV 为无符号 16 位，高字节在前。

### 2.3 IO 位图（CMD=0x10）

| bit | 信号 | 治具侧引脚 |
|---|---|---|
| 0 | KEY3 | PC4 |
| 1 | KEY4 | PC5 |
| 2 | KEY1 | PB0 |
| 3 | KEY2 | PB1 |
| 4 | TBS | PB10 |
| 5 | KEY0 | PB11 |
| 6 | TEST-INT | PC8 |
| 7 | MMS | PA15 |

位值：1 = 高电平，0 = 低电平。

## 3. 示例

```
PING 应答，版本 1：
A5 5C 01 01 01 D9 EB

IO 应答，8 路位图 0x55（KEY3/KEY1/TBS/KEY0 为高）：
A5 5C 10 01 55 23 BA

电压应答，3V3=2475mV，5V=3000mV，24V=3130mV：
A5 5C 11 06 09 AB 0B B8 0C 3A 05 4B

ADC 应答，NHT=1500mV，NTC=2000mV，MER=0，MER 电平=1：
A5 5C 12 07 05 DC 07 D0 00 00 01 8E 49
```

## 4. 副芯片侧要求

1. 上电后把 8 路 IO 全部配置为**输入**，不要开内部上下拉。
2. 收到 `0x10` 时返回当前 8 路电平位图。
3. 收到 `0x11` 时采样 U1-3V3、U1-5V、U1-24V 三路 ADC，返回 mV。
4. 收到 `0x12` 时采样 U1-NHT、U1-NTC 两路 ADC；MER 没有 ADC，mV 填 0，
   `[6]` 填 MER 引脚的数字电平。
5. 应答必须在收到请求后 60ms 内发出；治具最多重试 2 次。
6. 副芯片不响应时，治具会把副芯片的采集值按"通过"处理。

## 5. 治具侧对应实现

- `Core/Inc/fx_bus.h`、`Core/Src/fx_bus.c`：帧层、CRC、请求/应答。
- `fx_bus_subchip_read_io()` / `fx_bus_subchip_read_volt()` /
  `fx_bus_subchip_read_adc()`：供检测功能调用。
