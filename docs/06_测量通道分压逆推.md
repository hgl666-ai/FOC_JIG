> （分压比、通道号、MCU 脚都对得上），但下面这两条当年的结论要改：
> - §1 说"每个通道后面都有 100Ω + 1nF + SMF3.3A" —— **只有 6 路相电压通道有**，
>   24V/10V/5V/3.3V/电流两路的 ADC 网络段上没有这组 RC；
> - 当年没注意到、后来才查清的：**编码器座 CN2 的 A/B/Z 也进 MCU 定时器脚**
>   （U1、U2 的 PB6/PB7/PB8），**电机输出端 MA0_OUT 组则只有 ADC 通路、没有定时器通路**。
>   详见 `docs/00` §3.5 / §3.6。

## 1. 一句话结论

治具一共测 **9 路模拟量**（4 路电源电压 + 3 路相电压 + 2 路电流检测），
**每一路都同时缓冲成两份**分别送给 U1 和 U2 的 ADC：
前级分压/跟随 → 100Ω + 1nF + SMF3.3A → ADC 引脚。全部是**电压跟随器（增益 1）**，
所以传递函数就是分压比本身。

- "串"= 串联（信号侧），"并"= 对地并联。
  **只有 6 路相电压通道**（U1 的 IN6/IN7/IN8、U2 的 IN2/IN3/IN4）后面有
  **100Ω + 1nF + SMF3.3A** 的 RC + TVS 保护，再进 ADC 引脚（2026-10 更正：原版说"每个通道都有"，不对）；

- 电流两路没有分压，被测的是被测板自己的电流采样输出电压（量程 0~3.3V）。

  测试点 → 一段直导线 → **对地 SMF3.3A**（`D16`/`D17`）→ 缓冲运放的同相输入端。
  **无串阻、无分压、无 RC**。也就是说治具在这一路上只有"读"的角色，
  原理图上**没有任何治具 MCU 引脚接在这根线上**（要往里灌信号得另外加线，见 `docs/00` §3.5 第 4 条）。

## 3. 硬件工程师自己写在图上的三个数，我复算过

图上 24V/10V 分压那一块写着：

```
采样电压不能低于7V
24V：3.04032
10V：1.2668
7V ：0.88676
```

用 k = 4.7 / (32.4 + 4.7) = 0.12668 复算：

| 输入 | k×输入 | 图上标注 | 结论 |
|---|---|---|---|
| 24 V | 3.04032 V | 3.04032 | ✅ 完全一致 |
| 10 V | 1.26680 V | 1.2668  | ✅ 完全一致 |
| 7 V  | 0.88676 V | 0.88676 | ✅ 完全一致 |

**分压设计本身没问题**，三个数是同一套 0.12668 的比例算出来的。
三相那一块的 `24*20/（140+20）` 也一样：24 × 20/160 = 3.0 V ✅。

## 4. 固件换算公式

```c
/* VDDA 最好用内部 VREFINT 反算，不要写死 3.3 */
V_signal = adc_counts * (VDDA / 4095.0f) / k;      /* k 见上表第 4 列 */
```

按 VDDA = 3.3 V 化简后，每 1 个 ADC 码值代表：

| 通道 | 每 count 折算 |
|---|---|
| 24V / 10V | 6.361 mV |
| 5V | 1.343 mV |
| 3.3V | 0.886 mV |
| A/B/C 相 | 6.447 mV |
| 电流 1/2 | 0.806 mV |

标称输入时的期望读数（可用作自检/上下限的基准）：

| 输入 | ADC 电压 | 期望 counts（VDDA=3.3V） |
|---|---|---|
| 24 V | 3.040 V | ≈ 3773 |
| 10 V | 1.267 V | ≈ 1572 |
| 7 V | 0.887 V | ≈ 1100 |
| 5 V | 3.000 V | ≈ 3723 |
| 3.3 V | 3.000 V | ≈ 3723 |
| 相电压 24 V | 3.000 V | ≈ 3723 |

## 5. 需要确认/注意的四件事

1. **24V 通道余量偏紧**：24 V 标称 → 3.040 V，只占满量程的 92%；
   输入到 **26.05 V 就饱和**，而保护用的 SMF3.3A 击穿电压约 3.67 V，
   对应输入 ~29 V 就开始压。无刷电机减速回馈时母线抬到 26 V 以上是常事，
   要不要把分压比改小一点（例如 R14 换 3.9kΩ → k = 0.1074，满量程 30.7 V）？
2. **10V 通道只用掉 38% 量程**（10 V → 1.267 V），分辨率 6.36 mV 够用但偏浪费；
   如果要更细，需要给它单独配分压。
3. **5V 通道满量程正好 5.5 V**：5 V ±10%（4.5~5.5 V）时刚好顶到满量程，
   如果被测 5V 有可能超过 5.5 V，同样要考虑改比例。
4. **三相电压是"对功率地"采样**（图上标题"对功率地电压采样"）：
   治具的 GND 必须与被测板的**功率地 P-GND** 连在一起，否则读数没有意义。
   飞线/顶针设计时要把这一点带上。

## 6. 追踪过程中顺带确认的两件事

- **U1 与 U2 的 9 路完全重复**（18 个缓冲通道）：同一个信号既进 U1 的 ADC
  也进 U2 的 ADC。固件里到底谁负责采样（冗余交叉校验？还是分工：U1 取电压、
  U2 取电流？）需要定 —— 这直接决定测量功能的软件结构。
- U1 引脚标签的顺序与数据手册一致（U1_ADC1_IN0..IN8 = PA0..PA7 + PB0 ✅），
  `IN24V/IN10V/IN5V/IN3.3V` 是**被测板**引过来的输入点（图上标"被测点输入"），
  不是治具自己的电源。

## 7. 复现方法

```bat
python tools\sch_trace.py batch U1_ADC1_IN0 ... U1_ADC1_IN8   :: 查每个 ADC 脚接哪路
python tools\sch_trace.py net   INA                            :: 查某网络的整段连接
python tools\sch_trace.py near  700 290 62                     :: 查某点附近的元件
python tools\sch_trace.py dump  596 30 770 100                 :: 看某区域的原始线段
```
